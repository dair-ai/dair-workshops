# Context Compression

Context compression is the practice of reducing large working traces into compact summaries that preserve the information needed for future reasoning.

## Core Idea

The goal is not to remember every token. The goal is to keep the conclusions, constraints, decisions, and open questions that help future work continue.

## In The Source Notes

Memento is the clearest example. It compresses reasoning blocks into smaller mementos. Memory Transfer Learning points in a similar direction by showing that higher-level insights transfer better than raw execution traces.

## In This Demo

The wiki is a compression layer. Each paper page compresses a raw paper entry. Each concept page compresses patterns across multiple papers. Each question page compresses an exploration into a reusable answer.
