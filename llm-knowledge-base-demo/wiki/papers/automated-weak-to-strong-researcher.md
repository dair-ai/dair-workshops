# Automated Weak-to-Strong Researcher

Automated Weak-to-Strong Researcher is useful for understanding how agent teams can make measurable progress on research tasks.

## Why It Matters

The source note describes parallel automated researchers that propose ideas, run experiments, and iterate against an outcome metric. The system coordinates through shared findings and codebase snapshots, then measures progress with performance gap recovered. The key lesson for builders is that agent research workflows need clear metrics, durable collaboration artifacts, and careful oversight.

## Key Ideas

- Parallel research agents
- Shared findings
- Outcome-graded progress
- Reward hacking risk
- Isolated sandboxes with shared research memory
