# Memory Intelligence Agent

Memory Intelligence Agent is useful because it separates memory management from planning and execution.

## Why It Matters

Research agents need to decide what to keep, what to retrieve, what to compress, and what to internalize. A separate memory manager makes this responsibility explicit.

## Key Ideas

- Memory manager
- Planner
- Executor
- Conversion between retrieved context and internalized knowledge
- Test-time memory updates for evolving information

## Connection To This Demo

The compiler prompts act like a simple memory manager. They decide what raw material becomes a paper page, what becomes a concept page, and what should be filed as a derived answer.
