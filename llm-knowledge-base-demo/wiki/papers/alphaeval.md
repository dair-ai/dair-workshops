# AlphaEval

AlphaEval focuses on evaluating agents as products operating in real workflows.

## Why It Matters

Many agent benchmarks simplify tasks too much. Production agent work involves incomplete instructions, implicit constraints, fragmented inputs, and expert judgment. A useful benchmark should preserve some of that complexity.

## Key Ideas

- Product-level evaluation
- Production-specific failure modes
- Rubrics and formal checks
- Domain-specific judgment

## Connection To This Demo

The demo wiki should be evaluated by what it helps a builder do. Good checks include whether the wiki can produce a reading roadmap, explain a trend, identify missing pages, and support a live event.
