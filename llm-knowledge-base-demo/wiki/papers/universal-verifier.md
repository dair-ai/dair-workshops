# Universal Verifier

Universal Verifier is useful for this wiki because it focuses on whether an agent actually succeeded.

## Why It Matters

Computer-use agent benchmarks can overcount success when verifiers miss failures. Universal Verifier reduces false positives by combining non-overlapping rubrics, process and outcome rewards, cascading assessment, and divide-and-conquer context management over screenshots.

## Key Ideas

- Non-overlapping criteria
- Separate process and outcome rewards
- Cascading assessment of controllable and uncontrollable failures
- Full-trajectory context management

## Connection To This Demo

A knowledge base also needs verification. A compiler pass should not only create pages. It should check whether links resolve, raw batches are covered, concept pages cite relevant papers, and generated answers are filed in the right place.
