# Source Note: AI Papers of the Week, April 6 to April 12, 2026

Source collection: https://github.com/dair-ai/AI-Papers-of-the-Week

This note is a compact raw input for the workshop compiler. It is meant to be easy for an LLM to read in one pass.

## Neural Computers

Neural Computers describe a direction where computation, memory, and I/O collapse into a learned runtime state. The paper treats neural models as potential computing substrates rather than only predictors or agents around external tools.

Useful wiki themes:

- Neural runtimes
- Learned computation
- Model-as-computer framing
- Long-term agent infrastructure

## Memento

Memento teaches reasoning models to compress their own reasoning blocks during generation. It creates compact mementos, evicts earlier reasoning blocks, and continues from compressed summaries.

Useful wiki themes:

- Context compression
- Reasoning memory
- KV cache reduction
- Experience compression

## Memory Intelligence Agent

Memory Intelligence Agent proposes a manager, planner, and executor architecture for research agents with evolving memory. The system focuses on transforming between retrieved context and model-internal memory.

Useful wiki themes:

- Memory managers
- Research agents
- Parametric and non-parametric memory
- Planner-executor workflows

## Single-Agent LLMs vs. Multi-Agent Systems

This paper questions whether multi-agent systems outperform single-agent systems when compute is controlled. It suggests that some apparent multi-agent gains may come from extra test-time computation rather than coordination itself.

Useful wiki themes:

- Single-agent baselines
- Multi-agent evaluation
- Test-time compute
- Coordination overhead

## RLM

Recursive Language Models treat a prompt as a manipulable object that can be inspected, decomposed, and recursively processed. The pattern helps with inputs beyond ordinary context windows by letting the model selectively examine relevant chunks.

Useful wiki themes:

- Recursive prompting
- Long-context processing
- Programmatic decomposition
- Search over source material
