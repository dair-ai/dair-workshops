# Source Note: AI Papers of the Week, April 13 to April 19, 2026

Source collection: https://github.com/dair-ai/AI-Papers-of-the-Week

This note is a workshop-sized raw source document. It intentionally keeps only a small set of papers that are useful for demonstrating how an LLM can compile raw notes into a structured wiki.

## Automated Weak-to-Strong Researcher

Anthropic demonstrates automated progress on scalable oversight research. Parallel Claude-based research agents propose ideas, run experiments, and iterate on weak-to-strong supervision. The system reportedly recovers most of the remaining performance gap on the target setup and shows that agent teams can make measurable progress on outcome-gradable research problems.

Useful wiki themes:

- Automated research agents
- Parallel agent coordination
- Alignment evaluation
- Metric design and reward hacking

## AiScientist

AiScientist frames long-horizon AI research as a state-management problem. Its core pattern is file-mediated coordination. Plans, analyses, logs, experiments, and evidence live as durable workspace artifacts so agents can recover context without replaying long conversations.

Useful wiki themes:

- File-as-bus coordination
- Durable agent memory
- Long-horizon research workflows
- Thin control and thick state

## AlphaEval

AlphaEval evaluates commercial agent products on production-grounded tasks rather than clean benchmark prompts. The benchmark emphasizes real workflow complexity, including implicit constraints, fragmented inputs, expert judgment, and product-level behavior.

Useful wiki themes:

- Production-grounded agent evaluation
- Product-level benchmarks
- Failure modes in deployed agents
- Rubric and formal verification blends

## Memory Transfer Learning

Memory Transfer Learning studies whether coding-agent experience can transfer across domains. The central claim is that high-level procedural insights transfer better than raw traces or task-specific code.

Useful wiki themes:

- Agent memory abstraction
- Cross-domain transfer
- Procedural guidance
- Coding agent learning

## WebXSkill

WebXSkill extracts reusable web-agent skills from trajectories. It turns repeated web tasks into reusable guidance or executable action programs, improving web-agent success on repeated flows.

Useful wiki themes:

- Skill extraction
- Web agents
- Reusable action programs
- Guided versus grounded execution
